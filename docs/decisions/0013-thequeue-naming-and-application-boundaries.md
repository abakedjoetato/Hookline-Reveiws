# ADR 0013: TheQueue Brand Naming and Application Boundaries

## Status
Approved

## Context
We need a consistent platform brand naming convention for documentation, Swagger documents, UI applications, and Docker naming conventions.

## Decision
We adopt **TheQueue** as the platform name across all user-facing systems, metadata files, and local containers, while keeping the internal package namespaces mapped as `@platform/*`.

## Consequences
- Highly cohesive brand identity.
- Clean technical naming boundaries.
- Consistent application definitions.
